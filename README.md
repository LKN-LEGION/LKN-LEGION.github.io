# FGStudio

A simple static website built with HTML, CSS, and a small JavaScript file. No build tools or dependencies are needed.

## Open on your computer

Double-click `index.html`. The website will open directly in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, `og-en.png`, `.nojekyll`, and the `games` folder.
2. Open **Settings → Pages** in the repository.
3. Select **Deploy from a branch**, choose **main**, and select **/(root)**.
4. Save. GitHub will show the published website address when it is ready.

For the best social-sharing preview, replace the `og:image` and `twitter:image` values in `index.html` with the full public URL of your published `og-en.png`.
